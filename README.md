Catálogo - Patrón de Diseño en Java
Implementación del patrón de diseño Catálogo/Factory y manejo de colecciones en Java. Proyecto académico de POO y patrones de diseño.

Simula un sistema de catálogo de productos donde se pueden agregar, buscar, listar y eliminar elementos.

🛠️ Stack
Java
POO (Herencia, Polimorfismo, Encapsulamiento)
Patrones de Diseño (Catálogo, Factory)
Colecciones (ArrayList, HashMap)

✨ Funcionalidades
Agregar productos al catálogo
Buscar por ID / nombre
Listar catálogo completo
Eliminar y actualizar productos
Manejo de excepciones

🚀 Cómo ejecutarlo
bash
javac Catalogo.java
java Catalogo

🧠 Qué aprendí
Aplicación de patrones de diseño para código reutilizable
Uso de colecciones en Java
Principios SOLID básicos
Separación de modelo y lógica de negocio

🔜 Mejoras futuras
Persistencia en archivo o MySQL
API REST con Spring Boot
Tests unitarios con JUnit
